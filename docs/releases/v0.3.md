Списки обновляются в работающем сервисе независимо от выпуска образов. Приложение получает проверенные снимки из `iplist-go-sidecar`, переключает каталог и экспорты без перезапуска и выполняет собственное DNS-обогащение.

Изменения:

- Проверка обновлений при старте и каждые 30 минут; интервал задается через `IPLIST_SNAPSHOT_INTERVAL`.
- Скачивание только изменившихся сжатых объектов, проверка SHA-256, размеров, структуры и состава наборов. При ошибке продолжает работать последняя проверенная версия.
- Сохранение снимков в runtime-volume и резервный снимок в образе для запуска без сети.
- Статусы свежести источников в UI, runtime API и заголовках экспортов. `/healthz` проверяет процесс, `/readyz` — наличие пригодного снимка; свежесть источников проверяется отдельно.
- DNS-кэш по доменам и семействам адресов: независимые таймауты A/AAAA, подтверждение отрицательных ответов, сохранение предыдущих ответов при временных сбоях с ограничением срока хранения.
- Исключение частных, loopback, link-local, multicast, неопределенных и CGNAT-адресов из DNS-добавлений. Явные адреса исходных списков сохраняются.
- Образы для `linux/amd64` и `linux/arm64`, проверки конкурентных обновлений, восстановления снимков и DNS-сбоев.

Обновление с v0.2:

1. Сохраните резервную копию конфигурации и runtime-volume. Используйте образ `ghcr.io/dexogen/iplist-go:v0.3`; постоянный volume должен охватывать `/app/runtime` и быть доступен для записи пользователю контейнера (UID 1000).
2. Источник по умолчанию — `https://github.com/dexogen/iplist-go-sidecar/releases/download/data/manifest.json`. Для собственного издателя задайте `IPLIST_SNAPSHOT_URL`. Старый каталог `config/` в Git-репозитории sidecar больше не используется.
3. Проверьте DNS-настройки: теперь по умолчанию используется системный DNS контейнера. Для своих резолверов задайте `IPLIST_DNS_SERVERS`; использование DNS из исходных конфигов включается явно через `IPLIST_DNS_USE_SOURCE_SERVERS=true`.
4. Проверьте `/readyz`, статусы источников и нужные экспорты. Существующие API URL и форматы сохранены. Если используется проверка свежести в `iplist-go-unifi`, сначала обновите `iplist-go`, затем синхронизатор.

```bash
docker pull ghcr.io/dexogen/iplist-go:v0.3
```
